# tpmk_analyzer_streamlit


Запуск файла streamlit из корня:
```
streamlit run frontend/app.py
```

### UI слой
При открытии приложения попадаем на главную страницу.
На главной странице у нас есть меню (header): Обработка, Отчеты, Регистрация, Логин
- Левая Боковая панель: содержит иконки всех отчетов по категориям: Отчеты по продажам (Отчеты ОПТа, отчеты розницы), Отчеты По закупу.... Они дублируют отчеты в header.... дальше будем дополнять.

- На центральной части главного окна выводятся ключевые показатели:
1. Анализ динамики оборота, оборота в себестоимости, валовой прибыли в виде столбчатой диаграммы по всему ассортименту в факте по месяцам за последние 6 месяцев
2. Сумма товаров в себестоимости и доля от общего остатка по товарам со статусом "выведено из ассортимента" и датой прихода на склад больше 6 месяца от текущей даты в разрезе group_1
